01
Dhakker — Hajj & Umrah Companion
FLUTTER · FIREBASE · CLOUDFLARE WORKERS

Graduation project. Auto-counts Tawaf and Sa'i circuits through GPS and sensor fusion, with a voice assistant.

REPO ↗

Problem

Pilgrims need Arabic-first guidance while their hands are busy, and counting circuits manually is exactly what breaks concentration.

Approach

Flutter with Firebase Auth and Firestore for the data layer, GPS geofencing fused with device sensors for circuit detection, and a voice assistant for hands-free use. Every API key is proxied through a Cloudflare Worker so nothing sensitive ships in the app bundle.

Result

Project testing recorded over 95% location accuracy across the tested location workflow.

Connects property managers, residents and technicians across the full maintenance request lifecycle.

REPO ↗

Problem

03
Waqfa — Purchase Decision Tool
FLUTTER · DART · GROQ API

Shows what a new instalment does to your cash flow before you commit to it.

REPO ↗

Problem

A single instalment always looks affordable on its own. The damage shows up weeks later, when several of them land in the same month.

Approach

A deterministic 90-day cash-flow calculation from income and expense inputs. The language model is kept out of the arithmetic entirely and only writes the Arabic explanation of a result it did not compute.

Result

Every number on screen is traceable to the local engine, so the output can be checked rather than trusted. Built at Amad Hackathon 2026; prototype scope, with no live BNPL provider connected.

REPO ↗

Problem

Approach
